# 精简回报历史索引

## 接口

- `GET /v1/history/sync`：按变异类型、作用域修订号及传输游标同步，最多 1000 条。作用域固定到 JWT 的组织或个人，管理员也不混合组织。
- `GET /v1/history/reports/:id`：受作用域保护的来源快照及最近 200 条调整审计；提供 `currentSource` 供前端安全跳转。

修订号在写事务中锁定并递增。传输限定水位，完整同步后继续接收水位之后的增量。完成游标使用 `revision:~`；数据库查询只比较修订号，不能使用受 locale 影响的 `id > '~'`。游标不可用返回 410，前端重新同步。

`history_reports` 保存精简来源投影；`history_scope_revisions` 保存作用域水位。删除发布仅含 ID、修订号和删除标识的墓碑。旧复核接口暂留，但新历史不读取旧复核事件。

## 回填

`/app/octopus history-backfill [--task UUID]` 默认只检查，`--execute` 才写入。按数据集批量读取经校验的缓存 Parquet，不逐行重复下载。仅回填当前回报或能确认曾回报的来源，跳过删除任务；缺失身份列入异常报告，未知时间保留未知。锁定当前调整并核对版本，防止迁移覆盖新修改。

重复执行幂等；不启动队列、不执行 CLI 数据库迁移、不申请节点、不修改余额。常规服务启动完成新模型迁移。

## 参考与验收边界

参考身份来自执行输入中的明确资源标识，忽略签名参数和 workflow alias；存在内容校验值时纳入身份。仅有资源路径不能证明被原地覆盖的 FASTA 内容未变化，历史未知参考不自动合并。

生产回填共 7 条（3 有效、4 撤回），重复写入 0、待核对 0。事务失败回滚、作用域拒绝、游标隔离、原始行提取、坐标与参考分组、旧执行及已替换数据集不可跳转均有回归覆盖。完整测试及构建通过。浏览器性能与生产页面验收边界见 YiJian 的 `docs/HISTORY_REPORTED_VARIANTS_20261007.md`。
