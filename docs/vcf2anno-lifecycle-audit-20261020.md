# VCF2Anno 生命周期核查（2026-10-20）

结论：代码已接入输入保留期、引用保护和结果保留期，但生产任务结果物理销毁尚未启用，不能宣称整个生命周期已经完成。

## 输入 VCF

- 生产 `DATA_RETENTION_DAYS=7`。VCF 与 FASTQ 共用上传确认、大小限制、资产状态与七天有效期；不享受 BED 的永久保存豁免。
- 任务创建、输入锁定及重试准备核验归属、完成状态和有效期。排队、运行及等待数据的任务引用会阻止手动删除和到期删除；任务结束后再按到期规则清理。
- 启动及每小时执行的资产清理服务独立于任务结果销毁开关。删除失败保留资产状态并重试，不先标记已删除。SaaS 不提供原始上传文件下载。
- 本轮补齐 SaaS VCF 的精确对象销毁：删除历史版本、删除标记和未完成分片，验证无残留；不会删除相同前缀的相邻文件。只有对象删除成功后才完成资产状态更新。
- 本地自部署默认不设置过期时间，仍允许管理员正常管理输入文件。

## 结果与任务

- 任务共用现有 720 小时保留期。规范化及注释 VCF/TBI、报表、预处理、性别说明、summary、报告、下载包及重建元数据随 attempt 归档管理。
- 结果到期后的访问限制、后台库存扫描及耐久清理作业已接入。物理销毁先确认所有执行停止、令牌撤销，再清理版本化归档对象、分片、缓存和业务记录；保留既有账务与到期防重建规则。
- 生产检查时 `RETENTION_CLEANUP_ENABLED=false`、`RETENTION_BACKUP_POLICY_VERIFIED=false`，因此到期结果尚不执行物理销毁。此轮不改变这些开关，也不执行历史数据删除。
- 生产当时尚无 VCF 输入资产或 VCF 任务，有 5 条通用结果清理作业。代码回归与模拟对象存储测试不等于生产真实 VCF 到期销毁验收。

## 暂停家系分析

两个版本保留家系工作流、组织流程和历史执行数据，但内置及组织家系流程展示为未开放；禁止新建、预估、批量创建、启动、重试和云端投递。历史结果读取、现有执行的状态回调与取消不受影响。
